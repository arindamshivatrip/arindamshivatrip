## 01 — Selected Work

### Reframed
<sub>MIXED REALITY · SPATIAL INTERACTION · CREATIVE TECHNOLOGY</sub>

A mixed-reality experience that makes physical framed artworks come alive through spatially anchored animation and interaction.

Rather than replacing the artwork with a virtual scene, **Reframed treats the physical piece as the interface**: elements animate within it, escape its boundaries, occupy the room, and encourage visitors to move and look differently.

**Exhibited:** NextNOW Fest · Henson Mania 2026  
**Built with:** Unity · C# · Meta Quest · spatial interaction

[View portfolio →](https://www.arindamtripathi.com)

---

### SnaPT
<sub>BROWSER ENGINEERING · HUMAN–AI INTERACTION · PERFORMANCE</sub>

A Chrome extension built around a simple problem: **very long ChatGPT conversations become increasingly painful to use**.

SnaPT reduces browser overhead from older conversation content while preserving access to the history, making long-running AI workflows faster and easier to navigate.

**Built with:** JavaScript · Chrome Extension APIs

[Repository →](https://github.com/arindamshivatrip/SnaPT)

---

### Aura Desk
<sub>SMART GLASSES · ANDROID XR · AMBIENT COMPUTING</sub>

An ambient spatial workspace concept built during an **Android XR hackathon using XREAL Project Aura**.

Aura Desk explored what a desk becomes when information no longer has to live inside a rectangular monitor: glanceable, spatially anchored widgets positioned around the user's physical workspace.

**Exploring:** ambient interfaces · spatial UI · smart glasses · context-aware interaction

[View portfolio →](https://www.arindamtripathi.com)

### Promo Optimizer
<sub>MACHINE LEARNING · DECISION SUPPORT · PRODUCT SYSTEMS</sub>

### ShooT IT
<sub>AUGMENTED REALITY · PHYSICAL COMPUTING · MULTIPLAYER</sub>

A real-time AR laser-tag system combining physical hardware, multiplayer synchronization, haptic feedback, and mobile augmented reality.

The project explored how physical action and digital state can remain synchronized during fast, embodied multiplayer interaction.
